# 英语预习小助手

给自家孩子用的英语课前预习工具，内容跟苏教版（译林版）小学英语教材同步。
纯网页应用，**不需要安装、不需要服务器、不花钱**。

## 🌐 在线地址（推荐用这个）

**https://qinliu2018.github.io/english-prep/**

iPad / 手机 / 电脑浏览器直接打开就能用。

**iPad 一次性安装（之后不开电脑、没网也能用）：**

1. 用 Safari 打开上面的网址
2. 点 Safari 底部「分享」按钮 →「添加到主屏幕」
3. 以后点主屏幕图标进入，和 App 一样，**离线可用**

## 发布更新（重要）

改了 `data.js` 等文件后，在本目录运行：

```
python deploy.py
```

它会通过 GitHub API 直接发布（国内网络下 `git push` 直连经常失败，
`deploy.py` 走的通道更稳）。发布后等 1 分钟左右刷新页面即可看到新内容。

## 电脑上怎么用

直接双击 `index.html`（推荐用 Edge 或 Chrome 打开）。

## iPad / 平板上怎么用（推荐）

1. 平板和电脑连同一个 WiFi
2. 在电脑上双击 `在iPad上用.bat`（窗口里会显示电脑的 IP 地址）
3. 平板浏览器打开 `http://电脑IP:8642`（例如 `http://192.168.1.5:8642`）
4. 在平板浏览器里点「分享 → 添加到主屏幕」，以后点图标就能进，像 App 一样

> 注意：学习进度存在平板浏览器本地，电脑和平板上的进度是各自独立的。
> 如果想随时随地用（不依赖家里电脑开机），以后可以部署到免费静态托管，到时候再弄。

## 怎么加新一课 / 新一册

打开 `data.js`，复制一个现成单元的整块内容照着改：

```js
{
  title: 'Unit 9 xxx',
  words: [
    { en: 'apple', zh: '苹果', emoji: '🍎', ex: 'I like apples.' },
    { en: 'banana', zh: '香蕉', emoji: '🍌' }   // ex 例句可以省略
  ],
  sentences: [
    { en: 'This is an apple.', zh: '这是一个苹果。' }
  ]
}
```

新一册录好后，把该册的 `ready: false` 改成 `true`，首页就会亮起这本书。

## 新增功能说明

### 作业本（每日任务）

**默认是自动排**：在学哪几本书 **App 里直接选**——首页点「📚 学习规划」，勾上孩子正在学的册（可多勾几本），保存即生效，之后「今日作业」每天自动为这些册出题。换年级、加初中词汇表都在这儿点一下，不用改代码。

`data.js` 最上方的 `HW_PLAN` 是进阶配置，一般不用动：

```js
const HW_PLAN = {
  books: ['3a'],   // 首次打开时的默认在学册（App 里勾选过就以 App 为准）
  daily: 3,        // 每册每天最多几项
  types: []        // 只排指定题型，留空 = 全部六种
};
```

每天自动为每册生成最多 `daily` 项任务，题型从「复习单词 / 测一测 / 听写 / 拼词 / 书写 / 填空」中**按日期轮换**（天天不同、一周轮一圈，当天重复打开不变）；单元没有合适课文就自动跳过「填空」。作业永远排在每册**当前重点单元**（第一个未达 3 星的单元），掌握后自动推进，每天零点重置打卡。

想完全手工安排，把 `HOMEWORK` 数组填上即可（非空时优先于 `HW_PLAN`）：

```js
const HOMEWORK = [
  { id: 'hw1', title: '预习 Unit 1', book: '3a', unit: 0, action: 'review' },
  { id: 'hw2', title: 'Unit 1 测一测', book: '3a', unit: 0, action: 'quiz' },
  { id: 'hw3', title: 'Unit 1 听写', book: '3a', unit: 0, action: 'dictation' }
];
```

`action` 可选：`review`（单词卡）、`sent`（课文跟读）、`quiz`（测一测）、`dictation`（听写）、`spell`（拼词游戏）、`trace`（书写练习）、`cloze`（填空）。

首页会显示「今日作业」进度；孩子点「去完成」进入任务。`quiz` / `dictation` / `spell` / `cloze` **做完才自动打勾**（中途退出不算完成），`review` / `sent` / `trace` 点开即打勾，任何任务也可以点整行手动勾选/取消。

### 学习报告（家长页）

首页工具栏点「学习报告」，可查看：连续打卡天数、已测/掌握单元数、错题本数量、最近 7 天活跃度柱状图。

### 全册总测

进入某册后，顶部有「🎯 全册总测」按钮，会从全册所有单词中随机抽题。

### 听写 / 拼词 / 书写

进入单元页后，「测一测」下方出现三个按钮：

- **听写**：看中文、听发音，输入英文拼写。
- **拼词游戏**：听发音，把打乱的字母按顺序拼回去。
- **书写练习**：在描红区用手指/笔描写，默认练习 26 个字母，进入单元后练习该单元单词。

## 常见问题

- **没有声音**：用 Edge / Chrome / Safari 打开；如果在微信里打开的，
  点右上角「···」→「在浏览器打开」
- **进度/星星丢了**：进度存在浏览器本地存储里，清除浏览器数据会丢；
  长期不用，Safari 可能自动清理。丢了也不影响使用，重新测一次就回来了
- **语速**：单词卡有「🐢 慢」按钮，课文跟读页有「慢速」开关，预习阶段建议慢速
